// 03 - Tools

Guvenli Dokuman Platformu

PDF operasyonlari ve AI destekli CV uretimi icin, gercek bir startup MVP'sine yakisan guvenlik, gizlilik, worker izolasyonu ve net servis sinirlariyla tasarlanmis bir urun vitrini.

Platform Scope

PDF islemleri, AI resume olusturma ve privacy-first pipeline ayni catida.

Next.js tabanli arayuz, TypeScript API, queue destekli izole worker'lar, signed URL indirmeleri ve retention politikasi ile ciddi bir SaaS temeli.

Next.js App Router TypeScript strict Tailwind UI NestJS / Express BullMQ + Redis PostgreSQL S3 storage Sandbox workers
Job Architecture

Yukle, izole ortamda isle, kisa omurle teslim et.

1

Upload asamasinda MIME, extension, magic byte ve dosya limiti kontrolleri uygulanir.

2

Dosya gecici izole storage'a tasinir, orijinal dosya adi asla guvenilmez.

3

API, is tanimini BullMQ sirasina yollar; worker kendi job klasorunde calisir.

4

Sonuc sadece kisa omurlu signed URL ile indirilir, ardindan cleanup job devreye girer.

PDF Tools

Cekirdek belge islemleri

Merge PDF Split PDF Compress PDF Rotate PDF Reorder Pages Delete Pages Extract Pages Watermark Page Numbers Protect PDF Unlock PDF Repair PDF PDF to DOCX PDF to PPTX PDF to XLSX PDF to JPG/PNG JPG/PNG to PDF Word to PDF PowerPoint to PDF Excel to PDF
AI CV Builder

ATS ve creative modlu resume editor

Step wizard ve tek sayfa editor modu ile hizli duzenleme akisi.
Live preview, drag and drop section siralama, template switcher ve autosave.
Summary, experience bullet, skills formatting ve cover letter icin AI destek aksiyonlari.
PDF, JSON ve plain text export; lokal draft ve hesap bazli kayit destegi.
Cok dilli icerik, photo upload/crop ve LinkedIn import icin hazir entegrasyon boslugu.
Security + Privacy

Upload, auth ve retention katmanlari ilk gunden sert.

MIME, extension, magic byte, page count ve conversion limit kontrolu.
Antivirus / ClamAV plug-in mimarisi ve supheli dosyalar icin quarantine akisi.
Non-root worker, read-only filesystem, per-job temp klasor ve outbound network kapatma.
Argon2 veya bcrypt ile auth; secure cookie, CSRF, RBAC ve ownership kontrolu.
Signed download link, audit log, anomaly hook ve GDPR farkindaligi olan retention kurallari.
API + Ops

REST, queue ve observability tek yuzde toplanir.

POST /api/files/upload - validation + quarantine-aware upload
POST /api/jobs - enqueue secure PDF conversion or transform
GET /api/jobs/:id - progress, status, retry and failure details
GET /api/download/:token - short-lived signed delivery
POST /api/resumes - create resume with versioned sections
POST /api/resumes/:id/export - PDF, JSON or plain text output
GET /api/admin/metrics - uploads, failures, worker load, suspicious activity
Data Model

Resume versiyonlama, islemler ve indirmeler icin schema omurgasi

users sessions roles uploaded_files processing_jobs job_results resumes resume_versions resume_sections ai_generations download_tokens audit_logs subscriptions invoices
Delivery Blueprint

Uretim odakli MVP temelinde cikan ana parcalar

Frontend Hero, tool grid, CV workspace, dark mode ve mobil uyumlu akislar.
API Auth, file lifecycle, jobs, resume CRUD, admin metrics ve audit endpointleri.
Workers pdf-lib, qpdf, Ghostscript, LibreOffice ve ImageMagick icin izole is katmani.
Ops Docker, env templates, cleanup cron, CI/CD ve temel test kapsami.

Monorepo yapisi, docker-compose, .env.example, seed veri, sample CV template'leri ve security notlariyla toy demo degil, ciddi bir temel hedeflenir.
